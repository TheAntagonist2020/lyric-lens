# Sources and evidence

Context can confirm a reading, add to it, or complicate it. It never replaces the text.

## Evidence tiers

| Tier | What it is | Examples | How to use it |
| --- | --- | --- | --- |
| A | The artist's own words | Interviews, liner notes, verified artist annotations on Genius, the artist's own posts and talks | Strong evidence of intent. Name the source and, if known, the date. |
| B | Documented facts | Songwriter and producer credits, release date, sample and interpolation sources (for example WhoSampled), label and chart history | Use freely when sourced. |
| C | Other people's readings | Crowd annotations, critics, fan theories, encyclopedia summaries | Leads, not proof. Attribute them and test them against the text. |
| D | Your own inference | The reading itself | Label it [Inference]. |

## With web access

- Search for tier A and B sources first: the artist's interviews about the song, the album's liner notes, verified annotations, credits, sample sources.
- Name each source and, when possible, give a link and a date.
- Use the web for context, not for the lyrics. Do not fetch a lyrics page in order to print the lyrics.
- If sources conflict, show the conflict. Do not pick the convenient one.

## Without web access

- Say so in one line.
- Give only facts you are confident of, and label them as from memory.
- List 2-4 specific things the user can check, so they can verify the reading themselves. For example: "Look for a verified artist note on the bridge on the song's Genius page", or "Check the album credits for a co-writer."

## Intent is evidence, not a verdict

An artist's statement about a song is strong evidence, but it is not the final word. Songs often mean more than their writers planned. Artists sometimes mislead on purpose, joke, or change their account over time. When the text supports a reading the artist never stated, keep the reading and label it [Inference]. When a statement conflicts with the text, show both.
