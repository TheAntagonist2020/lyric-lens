# Track a motif across a catalog

The artist and the motif to track: $ARGUMENTS

## Inputs

- **The artist and the motif**, theme, symbol, or recurring character (above). If either one is missing, ask for it.
- **The songs.** Best: the user pastes the relevant lines from each song. If not, list the songs where you believe the motif appears, label the list as from memory, and ask the user to paste the key passages before you make any claim that depends on exact wording.

## Steps

1. **Define the motif.** Say exactly what you track (a word, an image, a situation, a character) and what counts as an appearance. Note close variants.
2. **Build the timeline.** One row for each appearance, in release order:

   | Year | Song (album) | Where (lines or section) | How the motif is used | Change from the last use |
   | --- | --- | --- | --- | --- |

3. **Read the arc.** In a few short paragraphs: how the use changes, where it turns, and what stays fixed. Note callbacks, where a later song answers or revises an earlier line.
4. **Add context.** Tie a change to the artist's life or career only when a source supports it. See [the sources guide](../close-read/references/sources.md). Otherwise label the link [Inference], or leave it out.
5. **Name the gaps.** Say which appearances rest on memory instead of pasted text, and which songs the user should check.

## Rules

- Use the same evidence rules as `/lyric-lens:close-read`: cite lines, label confidence, keep quotes to a few words, and invent nothing.
- A common word is not a motif unless its use is distinctive. "Love" in 40 songs is not a motif. "The same red door" in 4 songs is.
- To read one song in depth, use `/lyric-lens:close-read`.
